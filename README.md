# QA Buddy Pro

An AI-assisted, end-to-end QA platform combining hybrid RAG, MCP integrations (Jira, Outlook), and a live dashboard.

## Status
Under construction - step by step build in progress.

## Stack
- Frontend: React + Vite (Vercel)
- Backend: FastAPI (Render)
- Vector DB: Qdrant Cloud
- Relational DB: Supabase (Postgres)
- LLM: Groq (cloud) + Ollama (local/offline mode)
- RAG orchestration: Langflow
- Integrations: Jira MCP, Outlook MCP
